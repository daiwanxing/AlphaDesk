## 1. 定位与关系

### 1.1 一句话

在「事件追踪」详情页增加 **AI 深度总结**：材料发布后自动生成一次，用户打开详情时只读已存结果。

### 1.2 与 V1 的关系

| 项 | 说明 |
|----|------|
| 模块归属 | 仍属 **事件追踪**，不新开独立模块 |
| V1 能力 | **保留**：固定信息区 + 官方材料链接 |
| V2 增量 | 并列增加 **AI 深度总结区** |
| 详情结构 | **三层并列**：固定信息 · AI 总结 · 官方链接 |

> V1 PRD §6.4「V1 不要求 AI 摘要」仍成立；本补丁定义 **V2 · AI 解读层**。

---

## 2. 要解决的问题

用户进入已发生事件详情后，仍需自行打开 IR / SEC / Fed 长文才能形成判断。希望：

- 打开详情即可读到**结构化深度总结**
- **不因每次刷新**重复消耗模型调用
- 材料未出 / 生成中 / 失败时状态诚实可见
- 仍可跳转**官方原文**核对

---

## 3. 产品目标与成功标准

### 3.1 目标

1. 已披露七姐妹财报：详情页展示标准结构的中文 AI 总结（见 §5）
2. 已召开 FOMC：Statement / Minutes / SEP **分卡**展示，各卡独立状态与内容
3. 材料可用后**尽快自动生成一次**；同一材料不因用户访问重复生成
4. 详情页请求**只读**已存结果，不触发现场 LLM
5. 未发生 / 生成中 / 失败态有明确、友好的产品表现（见 §6）

### 3.2 验收（单用户）

| 场景 | 通过条件 |
|------|----------|
| 已披露财报且摘要就绪 | 三层均可见；摘要含 §5.1 各块（有则写、无则标明原文未提及） |
| 刚披露、摘要未好 | AI 区为友好「撰写中」态；固定信息与官方链接可用 |
| 待披露财报 | AI 区为占位，**不**显示撰写中 |
| FOMC Statement 已发、Minutes 未发 | Statement 卡可读；Minutes 卡占位；SEP 按会议是否含 SEP 处理 |
| 生成失败 | AI 区明示失败 + 将自动重试；官方链接仍可用 |
| 重试耗尽 | AI 区明示失败且**不再**承诺自动重试；官方链接仍可用 |
| 重复打开同一事件 | 展示已存摘要，不表现为重新生成 |
| 切换历史年且材料已发布 | AI 区可最终就绪（允许补扫后生成；不得永久误显示「未发生」） |

## 4. 范围

### 4.1 做

| 能力 | V2 |
|------|-----|
| 七姐妹已披露财报 AI 总结（标准结构） | ✅ |
| FOMC Statement / Minutes / SEP 分卡总结 | ✅ |
| 未发生占位 / 撰写中 / 失败可见 | ✅ |
| 摘要标明「AI 生成 · 非正式官方文件」 | ✅ |
| 保留官方链接区供核对 | ✅ |
| 材料发布后自动生成；用户只读 | ✅ |

### 4.2 不做（本补丁）

- 买卖建议、仓位建议、目标价
- 未披露事件的「看点预告」类预解读
- 内嵌 PDF / 全文阅读器
- 用户手动点「重新生成」（失败靠自动重试）
- 多用户账号、订阅推送
- 同业对照深度篇（标准档不含 Mag7 横比）

## 5. 摘要内容定义（WHAT）

### 5.1 财报（标准 · 单篇）

语言：**中文**。数字尽量保留原文单位；原文未提及的块标明「原文未提及」，**不编造**。

| 块 | 说明 |
|----|------|
| 一句话结论 | 本季业绩与叙事的浓缩 |
| 核心财务数字 | 收入、利润、EPS、毛利率等文中出现的关键数字 |
| 同比 / 环比要点 | 有则写 |
| 分部 / 业务亮点 | 有则写 |
| 管理层要点 | 电话会/新闻稿中的关键表述摘要 |
| 展望与指引 | 有则写 |
| 风险 / 关注点 | 文中风险或值得跟踪的点；非交易建议 |

### 5.2 FOMC（分卡 · 标准）

每张卡独立：内容、状态、对应官方材料。

| 卡 | 摘要应覆盖 |
|----|------------|
| **Statement** | 利率决定；一句话政策立场；经济评估与风险表述 |
| **Minutes** | 委员分歧要点；政策路径讨论要点 |
| **SEP / 点阵图** | 利率路径/点阵图要点；增长/通胀/失业预测要点 |

- **本次会议不含 SEP**：该卡显示「本次会议不含 SEP」，**不生成**摘要
- **材料尚未发布**：该卡占位（同 §6.1），不显示撰写中

### 5.3 元信息（产品层须展示）

每篇/每卡摘要须可感知：

- 「AI 生成 · 非正式官方文件」
- 生成完成时间（若已就绪）
- 对应材料类型（财报 / Statement / Minutes / SEP）

## 6. 状态与用户可见表现

### 6.1 状态机（产品语言）

| 产品状态 | 何时出现 | 用户看到 |
|----------|----------|----------|
| **未发生** | 待披露 / 待召开；或 FOMC 某材料未发布 | 占位文案，如「披露/发布后将自动生成解读」——**不是**撰写中 |
| **撰写中** | 材料已可用，摘要排队或生成中 | 友好 loading / 撰写中效果 |
| **已就绪** | 摘要已写入并可展示 | 结构化摘要正文 |
| **失败** | 生成失败（将后台自动重试） | 「解读生成失败，将自动重试」；官方链接仍可用 |
| **失败耗尽** | 自动重试次数用尽 | 「解读生成失败」——**不再**写「将自动重试」；官方链接仍可用 |
| **不适用** | 如本场无 SEP | 「本次会议不含 SEP」 |

### 6.2 详情页三层（并列 · 已定）

1. **固定信息区** — 结构化事实，非 AI（沿用 V1）
2. **AI 深度总结区** — 见 §5、§6.1
3. **官方材料链接区** — IR / SEC / Fed（沿用 V1；供核对）

三层权重相近，不以「有摘要就隐藏链接」为产品原则。

### 6.3 生成时机（产品约束）

- **触发：** 材料变为可用后尽快自动生成（财报披露；FOMC 各材料各自发布时）
- **检测节奏（产品期望）：** **临近披露/会议窗口内加密检测**；无临近事件时仅 **日常低频兜底**——不是全年每天无差别高频空转（技术细节见 CloudBase 设计 §3.1.1）
- **幂等：** 同一事件 + 同一材料版本只生成一次成功结果；用户刷新不重跑
- **读路径：** 打开详情 = 读取已存结果；**禁止**因页面请求同步调用 LLM

## 7. 合规与诚实

| 要做 | 不做 |
|------|------|
| 标明 AI 生成、非正式官方文件 | 用摘要冒充官方声明或法定文件 |
| 保留官方链接供核对 | 删除或弱化到不可发现 |
| 原文未提及则标明 | 编造数字、指引、委员未说过的立场 |
| 沿用平台免责声明 | 给出买入/卖出/加减仓建议 |

页脚免责（沿用平台）：本工具仅提供研究信息聚合与整理，不构成投资建议。

## 9. 已确认项汇总

| 项 | 决定 |
|----|------|
| 详情主结构 | **三层并列**（固定信息 + AI + 官方链接） |
| AI 未就绪 | 友好「撰写中」loading；未发生用占位，不假装撰写 |
| FOMC 更新方式 | **按材料分卡**，各自独立状态与内容 |
| 财报摘要深度 | **标准**（§5.1） |
| FOMC 摘要深度 | **标准**（§5.2） |
| 未发生 AI 区 | **占位**，不做预解读 |
| 失败表现 | **失败可见 + 自动重试**；无手动「重新生成」按钮 |
| 检测节奏 | **窗口加密 + 日常兜底**（非全年无差别高频） |
| 落地形态 | 事件追踪详情增强，不新开模块 |
