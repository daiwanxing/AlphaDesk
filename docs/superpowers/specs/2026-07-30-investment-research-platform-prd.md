## 1. 产品定位

### 1.1 一句话

**信息聚合的投资分析研究平台** — 把分散在研究过程中的关键信息集中到一个地方，帮助用户更高效地跟踪、查阅、串联研究素材；**不替用户做投资决策**。

### 1.2 平台形态（产品层描述）

- 平台由多个**独立但可互通的研究模块**组成
- 每个模块解决一类研究信息问题（如：事件何时发生、某主题有哪些材料、某标的有何变化等）
- 用户可按研究需要进入不同模块；模块之间未来可共享「时间线」等概念，但**第一版不必强求**

### 1.3 当前范围说明

| 层级     | 状态                      |
| -------- | ------------------------- |
| 平台愿景 | 已确定方向                |
| 首个模块 | **事件追踪** — 已确定要做 |
| 其他模块 | 待定，后续迭代加入        |

> 说明：`2026-07-19-a-share-clue-engine-design.md`（A 股线索引擎）**已废弃**，不再作为本产品路线。平台级原则（如「不做买卖建议」）仍适用于本 PRD。

## 2. 背景与问题

### 2.1 问题

投资研究需要持续跟踪大量**按时间展开的事件**：公司财报披露、宏观政策会议等。这些信息：

- 分散在交易所公告、公司 IR、Fed 官网、财经日历等多处
- 日程与已发布内容往往不在同一入口
- 人工维护 Excel / 日历成本高，容易漏看或版本不一致
- 临近事件时，难以快速回答「七姐妹本周还有哪些财报要出」「下次 FOMC 什么时候」

### 2.2 平台要解决的问题（总）

> **把研究所需的信息聚合起来，减少「找信息」的时间，增加「读信息、做判断」的时间。**

### 2.3 首个模块要解决的问题（事件追踪）

> **让用户清楚知道：关心的事件什么时候发生；已经发生的事件，在哪里看详细内容。**

## 3. 产品目标

### 3.1 平台目标

- 成为个人投研的**信息中枢**，模块可逐步扩展
- 信息呈现**可追溯**（能回到原始来源或官方发布）
- 全平台遵守**研究辅助**边界，不提供买卖操作建议

### 3.2 模块目标（事件追踪 · V1）

用户打开「事件追踪」模块后，能够：

1. 查看**美股 Magnificent 7（七姐妹）**在**所选日历年**内各报告期的**财报披露日程**（默认当前年；含待披露 / 已披露状态）
2. 查看**美联储 FOMC** 在**所选日历年**内的会议日程（默认当前年；含待召开 / 已召开状态）
3. 对**已披露 / 已发布**的事件，进入详情页查看固定信息 + 跳转官方材料（见 §6.4）
4. **切换年份**，跳转查看指定年份的七姐妹财报与 FOMC 数据
5. 在一个时间维度上，汇总展示「七姐妹财报 + FOMC」接下来有什么、刚刚发生了什么

## 4. 成功标准（验收用）

### 4.1 平台级（长期）

| 指标       | 说明                                         |
| ---------- | -------------------------------------------- |
| 信息可达   | 模块内展示的信息能追溯到官方或权威来源       |
| 模块可扩展 | 新增模块时不破坏已有模块的使用               |
| 边界合规   | 全平台不出现买卖建议、仓位、目标价等决策输出 |

### 4.2 事件追踪 · V1（本版验收）

| 指标     | 说明                                                                           |
| -------- | ------------------------------------------------------------------------------ |
| 覆盖完整 | 所选日历年（默认当前年）内，七姐妹各报告期 + FOMC 日程均可查                   |
| 状态准确 | 每条事件能区分「待发生 / 已发生」；已发生事件可进入详情                        |
| 详情可用 | 已披露/已发布事件：详情页展示完整固定信息 + 可跳转的官方链接；未发布项明确标注 |
| 时效感知 | 用户能在 1 分钟内回答：「未来 2 周内七姐妹有哪些财报 / FOMC 会议？」           |
| 不做决策 | 模块只呈现日程与材料，不做涨跌预测、操作建议                                   |

**不作为 V1 成功标准：** 推送提醒准确率、全市场覆盖、AI 解读质量、移动端体验。

## 5. 非目标（明确不做）

### 5.1 平台级

- 实盘 / 模拟交易、跟单、信号订阅
- 买卖点、仓位、目标价、评分式「操作建议」
- 替用户下投资结论（「必涨必跌」「强烈看多/看空」作为指令）
- 第一期不做：复杂多租户、社交、评论社区

### 5.2 事件追踪 · V1

- 不做全市场覆盖（V1 **仅七姐妹 + FOMC**，不支持用户自选、不支持 A 股/港股等）
- 不做用户添加/移除公司、股票代码检索、关注列表管理
- 不做实时行情驱动的交易信号
- 不做财报 / FOMC 的 AI 摘要或「解读报告」（V1 只聚合与展示材料；解读可留给后续模块）
- 不做邮件 / 微信 / App 推送（可列入后续版本）
- 不做用户自定义任意宏观事件类型（V1 仅：**七姐妹财报 + FOMC**）

## 6. 模块需求：事件追踪（V1）

### 6.1 模块定义

**事件追踪**：按时间组织、展示用户关心的**可预期研究事件**及其**已发布材料**，帮助用户做研究排期与材料查阅。

### 6.2 事件类型（V1 仅两类）

| 类型             | 说明                                             | 示例                                         |
| ---------------- | ------------------------------------------------ | -------------------------------------------- |
| **公司财报披露** | 上市公司定期报告（季度为主）的预计或实际披露时间 | Q1/Q2/Q3/Q4 财报、年报                       |
| **FOMC 会议**    | 美联储公开市场委员会议息相关会议                 | 日程、声明、纪要、点阵图等（以实际发布为准） |

### 6.3 覆盖范围

#### A. 美股 Magnificent 7 · 财报（固定清单）

| 项       | V1 要求                                                                                 |
| -------- | --------------------------------------------------------------------------------------- |
| 市场     | **仅美股**                                                                              |
| 公司范围 | **固定 7 家**，产品预置，用户不可增删                                                   |
| 时间     | 以**日历年**为浏览单位；**默认当前年**；用户可**切换年份**查看指定年数据                |
| 粒度     | 以**公司 × fiscal 报告期**为一条事件                                                    |
| 状态     | **待披露**（预计日或「待公布」）/ **已披露**（实际披露日已知且 **公司 IR 材料可跳转**） |

**V1 固定覆盖（Magnificent 7）：**

| Ticker | 公司      |
| ------ | --------- |
| AAPL   | Apple     |
| MSFT   | Microsoft |
| GOOGL  | Alphabet  |
| AMZN   | Amazon    |
| META   | Meta      |
| NVDA   | NVIDIA    |
| TSLA   | Tesla     |

**V1 公司 IR 官网（已定 · 详情页主链接）：**

| Ticker | 公司      | Investor Relations                       |
| ------ | --------- | ---------------------------------------- |
| AAPL   | Apple     | https://investor.apple.com               |
| MSFT   | Microsoft | https://www.microsoft.com/en-us/investor |
| GOOGL  | Alphabet  | https://abc.xyz/investor                 |
| AMZN   | Amazon    | https://ir.aboutamazon.com               |
| META   | Meta      | https://investor.atmeta.com              |
| NVDA   | NVIDIA    | https://investor.nvidia.com              |
| TSLA   | Tesla     | https://ir.tesla.com                     |

> V1 **优先**跳转公司 IR 官网上的业绩/财报材料（Press Release、季度业绩页、Financials 入口等）。若无法自动定位到具体报告期页面，至少链到该公司 IR 首页，并在固定信息区标明报告期。  
> **SEC EDGAR** 作为**次要核对链接**（法定 10-Q/10-K filing），见 §6.4。

**报告期展示（已定）：**

- 按数据源 / 公司 **fiscal quarter** 原样展示（如 `FY2026 Q2`）
- 若数据源提供报告期结束日，一并展示（如「截至 2026-03-31」）
- 时间线排序按**预计/实际披露日期**

**用户应能感知的信息（每条财报事件至少）：**

- 公司名称、ticker
- **报告期**（如 `FY2026 Q2`）
- 预计披露日期和/或实际披露日期
- 当前状态（待披露 / 已披露）
- 若已披露：入口进入详情页（§6.4）

#### B. 美联储 · FOMC

| 项       | V1 要求                                   |
| -------- | ----------------------------------------- |
| 范围     | **FOMC 正式会议**日程（随所选日历年切换） |
| 粒度     | 以**单次会议**为一条事件                  |
| 状态     | **待召开** / **已召开**                   |
| 若已召开 | 入口查看详细内容（§6.4）                  |

**用户应能感知的信息（每条 FOMC 事件至少）：**

- 会议日期（及如需区分的公告发布时间）
- 会议序号或期次标识（如 2026 年第 X 次）
- 当前状态（待召开 / 已召开）
- 若已召开：入口进入详情页（§6.4）

#### C. 年份切换（已定）

| 项       | V1 要求                                                                |
| -------- | ---------------------------------------------------------------------- |
| 默认     | 打开模块时展示**当前日历年**                                           |
| 切换     | 用户可切换至**其他年份**，列表与时间线刷新为该年七姐妹财报 + FOMC 数据 |
| 边界     | 若某年无数据或超出数据源覆盖，明确提示；不展示空壳事件                 |
| 交互细节 | 具体控件（下拉 / 步进器等）留待交互设计                                |

### 6.4 「详细内容」的产品定义（V1）

对已发生的事件，用户进入**详情页**。详情页由两部分组成：**固定信息区** + **官方材料链接**。

#### 方案（已定）：以官方链接为主，不做内嵌正文/PDF

- **正文与 PDF 在官方站点阅读**；平台 V1 **不内嵌**财报全文、PDF 预览或 HTML 正文
- 详情页提供**可点击的官方链接**（新窗口打开）：**美股财报 → 公司 IR 官网**；**FOMC → Fed 官网**
- 未发布材料：链接区显示「尚未发布」，**不伪造**

#### A. 固定信息区（详情页必展示）

来自结构化数据，字段固定、**非 AI 生成**：

**财报事件（七姐妹）：**

| 字段               | 说明                                                                       |
| ------------------ | -------------------------------------------------------------------------- |
| Ticker、公司名称   | 固定七姐妹之一                                                             |
| 报告期             | 见 §6.3                                                                    |
| 预计披露日         | 若有（第三方日历，标注为预计）                                             |
| 实际披露日         | 已披露时                                                                   |
| 事件状态           | 待披露 / 已披露                                                            |
| 数据来源与更新时间 | 主：**公司 IR 官网**；辅：Nasdaq Calendar（预计日）、SEC EDGAR（披露校验） |
| Filing 类型        | 如 10-Q、10-K（已披露时，来自 SEC，可选展示）                              |
| Filing 日期        | SEC 接受日期（已披露时，可选展示）                                         |
| Accession / CIK    | 便于在 EDGAR 核对（已披露时，**次要链接**）                                |

**FOMC 事件：**

| 字段               | 说明                                                                                                                    |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| 会议日期           |                                                                                                                         |
| 会议期次           | 如 2026 年第 X 次                                                                                                       |
| 事件状态           | 待召开 / 已召开                                                                                                         |
| 各材料发布状态     | **Statement** / **Minutes** / **SEP·点阵图（Projection Materials）** — 每项标明「已发布 / 尚未发布 / 本次会议不含 SEP」 |
| 数据来源与更新时间 | 如「Federal Reserve · 更新于 …」                                                                                        |

#### B. 官方材料链接区

**财报详情（已定）：公司 IR 为主，SEC EDGAR 为辅**

| 优先级         | 链接             | 说明                                                                                                |
| -------------- | ---------------- | --------------------------------------------------------------------------------------------------- |
| **主**         | **公司 IR 官网** | 对应报告期的业绩材料入口：Press Release、Earnings / Quarterly Results、Financials 等；见 §6.3 IR 表 |
| **辅（可选）** | SEC EDGAR filing | 法定 10-Q / 10-K 索引页，供核对；文案如「SEC 法定 filing（核对用）」                                |

- V1 若无法自动解析到**具体季度页**，主链接为该公司 **IR 首页**，固定信息区须展示报告期，避免用户不知看哪一季
- V1.1 可增强：自动匹配 IR 上具体 earnings release URL

**FOMC 详情范围（已定 · 方案 B）：** Statement + Minutes + SEP/点阵图（Projection Materials）

| 事件类型                 | 链接目标（V1）                                                                                                                                       |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **已披露财报（七姐妹）** | **主：** 公司 IR 官网（§6.3）；**辅：** SEC EDGAR filing（可选）                                                                                     |
| **已召开 FOMC**          | Fed 官网，各自独立链接：**Statement**；**Minutes**（约会议后 3 周）；**Projection Materials**（含 SEP/点阵图，**仅含 SEP 的会议**，通常每年约 4 次） |

> 方案 B **可行**：三类材料均在 [Fed FOMC 日历页](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm) 提供官方 HTML/PDF 链接；无统一 JSON API，设计阶段需解析该页或等价官方来源获取链接。纪要晚于会议发布；非 SEP 会议点阵图应标「本次会议不含 SEP」而非伪造。

#### 原则

- 固定信息区只展示**可核对的事实字段**；链接区只指向**官方 URL**
- 有则展示，无则标明「尚未发布」或「暂无材料」，**不编造内容**
- V1 **不要求** AI 摘要、翻译、点评或内嵌阅读器
- 内嵌正文/PDF 预览列为 **V1.1+** 可选增强

### 6.5 核心用户场景

1. **排期：** 打开事件追踪（默认今年）→ 按时间查看未来两周七姐妹财报与 FOMC
2. **切换年份：** 选择 2025 → 查看该年已召开的 FOMC 与已披露财报详情
3. **查漏：** 某公司已披露 Q2 财报 → 列表状态变为「已披露」→ 详情页跳转 **公司 IR** 查看业绩材料（可选跳转 SEC 核对）
4. **宏观对照：** FOMC 已召开 → Statement 当天可看；数周后 Minutes、SEP 链接随发布出现
5. **按公司筛选：** 在七姐妹范围内按 ticker 筛选财报事件

### 6.6 模块内概念（产品语言，非技术）

| 概念       | 含义                                                       |
| ---------- | ---------------------------------------------------------- |
| **七姐妹** | V1 固定的 7 家美股 Magnificent 7，见 §6.3                  |
| **事件**   | 一条可按时间排序的研究事项（一次财报披露或一次 FOMC 会议） |
| **日程**   | 事件的发生时间（预计或实际）                               |
| **状态**   | 待发生 vs 已发生                                           |
| **详情**   | 详情页 = 固定信息区（结构化事实）+ 官方材料链接            |
| **来源**   | 材料的官方或权威出处，供用户核实                           |

## 8. 产品规则与边界

### 8.1 文案与合规

| 要做                             | 不做                     |
| -------------------------------- | ------------------------ |
| 展示事件时间与官方材料           | 给出买入/卖出/加减仓建议 |
| 标明材料来源与发布时间           | 承诺收益或暗示必涨必跌   |
| 日程为「预计」时明确标注不确定性 | 把预计日期表述为确定事实 |

**页脚免责（平台级，交互阶段落实文案）：**  
本工具仅提供研究信息聚合与整理，不构成投资建议。市场有风险，决策由用户自行做出并承担责任。

### 8.2 数据诚实

- 预计披露日、会议日为**第三方或规则推断**时，不得伪装成公司已公告的确定日期
- 材料未发布时，不得用模型生成内容冒充官方文件
- 若某公司已退市、停披露或数据源暂时缺失，应可见地标记，而非静默消失

| 能力                           | 是否可行          | 说明                                                                                                                        |

| 七姐妹：财报披露日程           | ✅ 可行           | 仅 7 个 ticker；Nasdaq 等公开 earnings calendar 或免费聚合 API 足够                                                         |
| 七姐妹：已披露 **IR 材料**链接 | ✅ 可行           | 七姐妹 IR URL **固定配置**（§6.3）；V1 可链 IR 首页，V1.1 可解析具体季度页                                                  |
| 七姐妹：披露日 / filing 校验   | ✅ 可行           | **SEC EDGAR**（`data.sec.gov`）免费；作辅助核对，非详情主入口                                                               |
| FOMC：会议日程                 | ✅ 可行           | Fed [FOMC 日历页](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm)；辅助 `calendar.json`（含部分 Fed 事件） |
| FOMC：**Statement**            | ✅ 可行           | 会议日官方 HTML/PDF，链在 FOMC 日历页                                                                                       |
| FOMC：**Minutes**              | ✅ 可行           | 约会议后 3 周发布；同页官方 HTML/PDF 链接                                                                                   |
| FOMC：**SEP / 点阵图**         | ✅ 可行（有条件） | 官方 **Projection Materials** PDF/HTML；**仅含 SEP 的会议**（通常每年约 4 次），非每场都有                                  |

**总体判断：方案 B（Statement + Minutes + SEP 链接）在 V1 可行。** 平台只需聚合**官方 URL** 与发布状态，不需解析点阵图数值。

### 9.2 主要数据来源（备忘，设计阶段再选型）

| 用途                           | 代表选项                                    | 费用        | 备注                                 |
| ------------------------------ | ------------------------------------------- | ----------- | ------------------------------------ |
| 七姐妹 earnings 日程           | Nasdaq 公开接口；Yahoo/Alpha Vantage 免费档 | 免费 / 限额 | 7 ticker 用量极小                    |
| 七姐妹 **IR 官网**             | §6.3 固定 URL 表                            | 免费        | 详情页**主链接**                     |
| 七姐妹 filing 校验             | SEC EDGAR `data.sec.gov`                    | 免费        | **次要链接**；披露日、10-Q/10-K 核对 |
| FOMC 日程                      | `fomccalendars.htm`；`calendar.json`        | 免费        | 链接解析以日历页为准                 |
| FOMC Statement / Minutes / SEP | 同上 FOMC 日历页各会议条目                  | 免费        | 需跟踪发布状态（Minutes 滞后）       |

### 9.3 产品层风险（需在 UI 中诚实呈现）

- **IR 页结构各异：** 各公司 IR 站点布局不同；V1 允许先链 IR 首页 + 标明报告期
- **美股日程为「预计」：** earnings date 来自第三方聚合；须标注预计
- **Minutes 滞后：** 会议后约 3 周才有链接；此前显示「尚未发布」
- **SEP 非每场都有：** 不含 SEP 的 FOMC 会议，点阵图区显示「本次会议不含 SEP」，不伪造
- **无统一 REST API：** FOMC 材料从 Fed 页面解析；七姐妹 IR 为固定 URL，季度深链 V1.1+
- **数据源变更：** 免费聚合接口可能调整；应提示「数据暂时不可用」
